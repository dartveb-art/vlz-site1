# ВЛЗ — тестовый стенд

Тестовая сборка Воскресенского Литейного Завода. Python FastAPI + Croncopia public metals data.

Развёртывание: Render Blueprint из этого репозитория. Health: `/api/health`. Котировки: `/api/quotes`.

Важно: облегчённая публичная тестовая версия. Не предназначена для реальных заявок и хранения персональных данных. Цены справочные; отсутствующие значения не подменяются.
